# AX Platform · LF Prototype

`index.html`을 브라우저에서 여시면 돼요. 서버 없이 파일만 열어도 동작해요(글꼴만 인터넷 연결이 필요해요).

## 보는 방법
- **전체 보기(처음 화면):** 25개 화면이 줄별로 펼쳐져 있고, 모두 실제로 동작해요. 아래 도구 막대에서 `전체 맞춤 · 50% · 100%`로 크기를 바꿔요.
- **프로토타입 실행:** `▶ 프로토타입 실행` 또는 화면 이름 옆 `▶ 이 화면부터 실행`을 누르면 1920×1080 한 화면씩 창에 맞춰 보여요. `Esc`나 `← 전체 보기`로 돌아와요.
- 주소 끝에 `?play#S05-Home`처럼 붙이면 그 화면부터 바로 실행돼요.

## 파일 구성
- `index.html` — 뼈대
- `css/app.css` — 공통 레이아웃 + 화면별 스타일 (`[data-screen="화면ID"]` 범위)
- `js/runtime.js` — 템플릿 해석기 ({{값}}, sc-for, sc-if, onClick 등)
- `js/screens.js` — 화면 25개의 템플릿과 동작 코드
- `js/app.js` — 전체 보기 / 프로토타입 실행 모드, 화면 이동
